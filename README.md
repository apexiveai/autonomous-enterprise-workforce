## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3001](http://localhost:3001) with your browser to see the result.

This project runs on port `3001` alongside Apexive Community. Its backend API
uses port `8004`; set `NEXT_PUBLIC_API_URL=http://127.0.0.1:8004` when running
the frontend outside Docker. `NEXT_PUBLIC_API_URL` must be an absolute HTTP(S)
URL and is required for production builds.

The frontend currently uses the backend's `/executions` create endpoint and
`/executions/{run_id}` detail endpoint. The backend does not currently expose
an execution-list endpoint, so the executions page explains this instead of
showing sample runs. Audit and approval views use `/audit` and `/approvals`.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
